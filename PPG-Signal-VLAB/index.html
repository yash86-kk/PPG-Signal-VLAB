Experiment 01

EXPERIMENT 01 — PPG SIGNAL & SIMULATION

Lab Overview

  • Signal: PLETH / PPG
  • Sampling Frequency: 125 Hz
  • Dataset: BIDMC PPG and Respiration Dataset

A. Introduction to PPG

Photoplethysmography measures changes in blood volume in the microvascular bed using optical sensing. It is widely used for pulse monitoring, heart-rate estimation, and biomedical signal analysis.

B. Applications

PPG signals support heart rate estimation, pulse waveform studies, motion artifact analysis, and biomedical signal interpretation in clinical and wearable systems.

C. Real PPG Dataset

The dataset used in this laboratory is derived from the BIDMC PPG and Respiration Dataset available through PhysioNet. The waveform below visualizes a real recorded PPG segment from the dataset.

D. PPG Simulator

A physiologically inspired PPG pulse is generated from heart rate, amplitude, baseline drift, and noise. Adjusting the parameters changes the waveform in a way similar to real acquisition conditions.

E. Interactive Waveform

The charts below compare the real recorded waveform with a generated synthetic signal, allowing students to study the relationship between physiological parameters and the observed PPG morphology.

EXPERIMENT 03 — CONVOLUTION LABORATORY

Input PPG Signal x[n]

Convolution combines the real normalized PPG input with a system response to show how a filter affects a biomedical signal.

Impulse Response h[n]

A normalized moving-average response used to smooth the input signal.

Parameter Control

5

Sets the number of samples in the moving-average impulse response h[n].

N = 5 → each sample of h[n] = 1/5

Discrete Convolution

y[n] = x[n] * h[n]

y[n] = Σ x[k]h[n-k]

How Convolution Works

y[n] = Σ x[k]h[n-k]

  1. Take the input signal x[n]. The real recorded PPG is used as the input.
  2. Generate the moving-average response h[n]. The selected Number of Samples determines N.
  3. Each sample of h[n] has value 1/N. Therefore h[n] = 1/N for n = 0, 1, ..., N - 1.
  4. Conceptually flip and shift h[n]. The h[n-k] term aligns the response with the input at each output index.
  5. Multiply overlapping samples. Pair each input value with its aligned impulse-response value.
  6. Add the products and advance. Each sum gives one y[n]; repeat until the full output is formed. Smaller N preserves more detail, while larger N averages more strongly.

More samples → wider averaging window → stronger smoothing.

The 5-sample moving average smooths the real PPG signal. Linear convolution produces 1254 output samples.

About

About the Virtual Lab

Purpose

PPG Signal V-Lab is an interactive virtual laboratory for understanding photoplethysmography and foundational signal processing. PPG represents changes in blood volume detected optically; students can observe how operations affect a recorded biomedical signal.

Dataset & Credits

The reference PPG waveform is derived from the BIDMC PPG and Respiration Dataset available through PhysioNet. Experiment 01 compares recorded and generated PPG, Experiment 02 explores signal operations, and Experiment 03 studies convolution with a moving-average response.
